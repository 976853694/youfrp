# 🚀 一键打包运行指南

## ⚠️ 当前状态

您的系统**尚未安装.NET SDK**，需要先安装才能编译打包。

---

## 📥 第一步：安装.NET 6.0 SDK

### 方式一：直接下载（推荐）

**点击下载链接：**
https://dotnet.microsoft.com/download/dotnet/thank-you/sdk-6.0.428-windows-x64-installer

直接下载安装程序，双击安装即可。

### 方式二：访问官网

1. 打开浏览器访问：https://dotnet.microsoft.com/download/dotnet/6.0
2. 找到 **.NET 6.0 SDK (v6.0.xxx)** 
3. 点击 **Windows x64** 下载
4. 下载完成后双击安装
5. 安装完成后**重启命令提示符**

---

## 🔨 第二步：编译打包程序

安装.NET后，打开**命令提示符**或**PowerShell**，执行以下命令：

### 进入项目目录
```bash
cd "E:\源码\内网穿透\FrpClient"
```

### 恢复依赖包
```bash
dotnet restore
```

### 编译项目
```bash
dotnet build -c Release
```

### 发布独立程序（包含.NET运行时）
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

**等待完成**（约2-5分钟，需要下载依赖包）

---

## 📦 第三步：获取可执行文件

编译完成后，程序位于：

```
E:\源码\内网穿透\FrpClient\bin\Release\net6.0-windows\win-x64\publish\
```

主程序文件：`南溪FRP.exe` （约60-80MB）

---

## 📥 第四步：下载frpc.exe

1. 访问：https://github.com/fatedier/frp/releases
2. 下载最新版本，例如：`frp_0.65.0_windows_amd64.zip`
3. 解压后找到 `frpc.exe`
4. 将 `frpc.exe` 复制到上面的 publish 目录中

**国内加速镜像**（如果GitHub慢）：
```
https://ghproxy.com/https://github.com/fatedier/frp/releases
```

进入发布目录：

## ❓ 常见问题

### Q1: 提示"dotnet不是内部或外部命令"
**A:** .NET SDK未正确安装或未添加到PATH环境变量
- 重新安装.NET SDK
- 重启命令提示符
- 重启电脑

### Q2: 编译时提示网络错误
**A:** 无法下载NuGet包
- 检查网络连接
- 或配置NuGet国内镜像：
  ```bash
  dotnet nuget add source https://nuget.cdn.azure.cn/v3/index.json -n huawei
  ```

### Q3: 发布后文件很大（60-80MB）
**A:** 这是正常的，因为包含了完整的.NET运行时
- 优点：可以在没有.NET的电脑上运行
- 如果想要小文件，可以使用框架依赖模式（需要目标电脑安装.NET）

### Q4: 找不到frpc.exe
**A:** 
- 确保frpc.exe在publish目录中
- 或复制frpc.exe到程序运行目录
