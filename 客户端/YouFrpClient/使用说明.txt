========================================
     南溪FRP客户端 - 使用说明
========================================

【系统要求】
  - Windows 10/11 操作系统
  - .NET 6.0 运行时环境
  - frpc.exe 客户端程序

【安装步骤】

1. 安装.NET环境
   - 访问: https://dotnet.microsoft.com/download/dotnet/6.0
   - 下载并安装 .NET 6.0 Desktop Runtime (桌面运行时)
   - 安装完成后重启计算机

2. 准备frpc客户端
   - 访问: https://github.com/fatedier/frp/releases
   - 下载最新版本的Windows客户端
   - 解压后将 frpc.exe 复制到本程序目录

3. 运行程序
   - 方式一：直接双击 "南溪FRP.exe" 运行
   - 方式二：命令行运行 "dotnet run"（开发模式）

【使用流程】

步骤1：登录
  ├─ 启动程序后进入登录界面
  ├─ 输入您的访问Token（向管理员申请）
  ├─ 可勾选"自动登录"保存Token
  └─ 点击"Token登录"按钮登录

步骤2：选择节点
  ├─ 登录成功后进入主界面
  ├─ 在"节点选择"下拉框选择合适的节点
  ├─ 系统会自动显示该节点的隧道列表
  └─ 节点选择会自动保存

步骤3：启动服务
  ├─ 查看隧道列表确认需要的隧道
  │  ├─ 绿色●表示隧道已启用
  │  └─ 灰色○表示隧道已禁用
  ├─ 点击"启动"按钮开始连接
  ├─ 查看运行日志确认连接状态
  └─ 状态显示"运行中"表示成功

步骤4：停止服务
  └─ 点击"停止"按钮断开连接

【隧道类型】

  TCP   - TCP端口映射
  UDP   - UDP端口映射
  HTTP  - HTTP协议映射（支持域名）
  HTTPS - HTTPS协议映射（支持域名）
  STCP  - 安全TCP映射（需要密钥）
  XTCP  - 点对点TCP映射（需要密钥）

【配置文件】

程序会自动生成以下文件：
  ▪ token.txt   - 保存的访问密钥
  ▪ node.txt    - 保存的节点选择
  ▪ frpc.toml   - 自动生成的frpc配置

【常见问题】

Q1: 提示"找不到frpc.exe"
A1: 请确保frpc.exe与程序在同一目录

Q2: 登录提示"访问密钥无效"
A2: 检查Token是否正确，或联系管理员

Q3: 隧道列表为空
A3: 该节点可能没有隧道，尝试切换节点

Q4: 启动后无法连接
A4: 检查网络连接和节点状态，查看日志

Q5: 如何开机自启动
A5: 将程序快捷方式放到开机启动文件夹
    路径：C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp

【技术支持】

如遇到问题：

  2. 查阅完整的 README.md 文档
